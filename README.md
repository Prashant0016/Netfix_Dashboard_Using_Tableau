# 📊 Netflix Dashboard [Using Tableau] 
This is a Data Visualization project where I created an interactive Netflix Content Dashboard using Tableau. The dashboard provides key insights about the content library of Netflix, such as:
 - Distribution of Movies vs TV Shows
 - Content added over the years
 - Top countries producing Netflix content
 - Genre-wise analysis
 - Ratings distribution
 - And more, with a total of 10 visualization charts, designed using Netflix’s signature Red & Black theme.

# 📂 Dataset
 - The Data set is provided by the author itself , you can download it via - https://github.com/DataScienceRoadMapDSRM/Tableau-Dashboards-info/blob/main/netflix_titles.csv
